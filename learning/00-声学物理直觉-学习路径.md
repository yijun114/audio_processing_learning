## Section 1: 声音是什么

### 直觉建立

声音的本质是**空气的振动**。

想象你敲一下鼓：鼓面快速来回振动，把旁边的空气先"推开"（压缩）再"拉回"（稀疏）。空气分子本身并不会一路跑到你耳朵里——它们只是在原地前后挤来挤去，把振动一层一层地传下去。这种"振动方向与传播方向一致"的波叫**纵波**（对比：绳子上下抖、波却向前走，那是横波）。

- 在**一个固定位置**（比如麦克风），你测到的是该点的气压随时间的变化——一条波形曲线
- 这条波形无论多复杂，都可以分解成不同频率的正弦波之和（傅里叶变换，你已经会的）

关键认知：**声音有三个独立属性**

1. **频率 $f$**：每秒振动多少次，单位 Hz，决定音调高低。语音主要在 100 Hz – 8 kHz
2. **幅度 $A$**：振动有多强，决定响度
3. **相位 $\phi$**：波"走到了周期的哪个位置"。同一频率的两个波，可以一个比另一个"晚到一点"，这个"晚多少"就是相位差——**声源定位主要靠它，后面会反复出现**

### 数学补充

纯音（单一频率）可以写为：

$$p(t) = A \sin(2\pi f t + \phi)$$

- $f$：频率 (Hz)，每秒完成的完整振动次数
- $A$：幅度
- $\phi$：初始相位（$t=0$ 时波在周期中的位置）
- 波长 $\lambda = c / f$，其中 $c \approx 343$ m/s（空气中的声速）

用波长公式体会一下数量级：1 kHz 的声音波长约 34 cm，8 kHz 的声音波长只有约 4 cm。频率越高，波长越短——记住这个感觉，第 4 节讲空间混叠时会用到。

## Section 2: 声波怎么传播

### 直觉建立

声源发声后，声波在空间中**向四面八方扩散**。根据你离声源的远近，可以用两种极端模型来描述它：

**球面波（近场）**：

- 像一个不断膨胀的气球：声波的能量分布在整个球面上
- 离声源越远 → 球面越大 → 单位面积分到的能量越少 → 声音越轻
- 能量按距离平方衰减；麦克风测到的声压则随距离线性衰减（距离每翻一倍，声压减半，即下降 6 dB）
- **波前是弯曲的** → 同一个波到达不同麦克风时，入射角度各不相同

**平面波（远场）**：

- 当你离得非常远、只看其中一小片球面时，这一小片几乎就是平的——就像站在地球上会觉得地面是平的
- **波前是平的** → 所有麦克风的入射角度相同
- 声源定位中**最常用的假设**：它把"声源在哪个位置"简化成"声音从哪个方向来"

什么时候用哪种？

| 条件 | 模型 |
|---|---|
| 声源距离 >> 阵列尺寸 | 平面波 ✅ |
| 声源很近（< 1m），阵列很大 | 球面波 |
| 大多数语音定位场景 | 平面波就够了 |

### 数学补充

远场条件：$r \gg \frac{2L^2}{\lambda}$，其中 $r$ 是声源到阵列的距离，$L$ 是阵列孔径（阵列两端麦克风之间的距离）。

代入数字感受一下：8 个麦克风、间距 3 cm 的线性阵列，孔径 $L = 21$ cm。对 1 kHz 的声音（$\lambda \approx 34$ cm），$2L^2/\lambda \approx 26$ cm——声源只要在 1 m 以外，远场假设就基本成立。但对 4 kHz 的声音（$\lambda \approx 8.6$ cm），这个距离变成约 1 m——**频率越高，越难满足远场条件**（这和后面第 4 节的高频混叠是同一个根源：λ 太短）。

实际上，大多数阵列声源定位都假设平面波——这不仅简化了数学，而且**即使有点误差，模型本身也足够鲁棒**。

## Section 3: 多麦克风为什么能判断方向

### 直觉建立

**这是整个声源定位方向最核心的物理直觉，请反复读三遍。**

想象两个麦克风排成一条线，间距为 $d$。声波从偏离正前方 $\theta$ 的方向传来（$\theta$ 是声波方向与阵列法线的夹角）：

```
声波从斜前方来（θ = 声波方向与阵列法线的夹角）：

   ●──────────●     麦克风阵列，间距 d
  Mic1      Mic2

   波前先到 Mic1，还要再走 d·sinθ 才到 Mic2
```

为什么是 $d \cdot \sin\theta$？把阵列、波前连成一个直角三角形：阵列是斜边（长度 $d$），而波前是"同一时刻到达"的等相位线——波到达 Mic1 之后，还要"等"波前扫到 Mic2，这段额外路程就是直角三角形的对边 $d \sin\theta$。

于是 Mic2 比 Mic1 晚到的时间：

$$\tau = \frac{d \sin\theta}{c}$$

这个时间差 $\tau$ 就是 TDOA (Time Difference of Arrival)。

- 声源在正前方（$\theta = 0^\circ$）→ $\sin\theta = 0$ → $\tau = 0$ → 两个麦克风同时收到
- 声源在正侧面（$\theta = 90^\circ$）→ $\sin\theta = 1$ → $\tau = d/c$ → 延迟最大
- 反过来：**测出 $\tau$，代入 $\theta = \arcsin(\tau c / d)$，就能算出 $\theta$**

这就是声源定位最底层的原理：**时间差 ↔ 方向，一一对应**。

**换个视角——在频域看更清楚**：

时间差 $\tau$ 在频域表现为**相位差**。一个完整的振动周期对应 $2\pi$ 的相位，频率为 $f$ 的波每秒振动 $f$ 个周期，所以"晚到 $\tau$ 秒" = "相位落后 $2\pi f \tau$"：

$$\Delta\phi = 2\pi f \tau = 2\pi f \frac{d \sin\theta}{c}$$

关键在于：**只要 $f$、$d$、$c$ 已知，相位差和方向就是一一对应的**。所以不同麦克风之间的相位差模式直接编码了方向。

反观幅度：两个麦克风离得很近，收到的幅度几乎一样（衰减差异可以忽略），**幅度里几乎没有空间信息**。空间信息在相位里，不在幅度里。

这也是为什么 Chakrabarty 2017 可以直接把 STFT 相位扔进 CNN——每个时频格的相位差（相对参考麦克风）已经包含了全部空间信息。

### 数学补充

考虑频率 $f$ 的纯音，从方向 $\theta$ 入射到间距 $d$ 的两个麦克风。以 Mic1 为参考：

- Mic1 收到：$A\sin(2\pi f t + \phi)$
- Mic2 收到：$A\sin(2\pi f (t - \tau) + \phi) = A\sin(2\pi f t + \phi - \Delta\phi)$

其中：

$$\Delta\phi = 2\pi f \tau = 2\pi f \frac{d \sin\theta}{c} = \frac{2\pi d}{\lambda} \sin\theta$$

### 检查点

- [ ] 我能画图解释"时间差 → 角度"的几何关系（直角三角形：斜边 $d$，额外路程 $d\sin\theta$）

- [ ] 我知道为什么相位差可以直接编码 DOA——不需要先提取特征

## Section 4: 空间混叠——为什么不能随便放麦克风

### 直觉建立

上一节说"一个时间差对应一个角度"。这里有个坑。

我们能测到的相位差只在 $-\pi$ 到 $+\pi$ 之间——相位是循环的，转满一圈 $2\pi$ 就回到起点（就像时钟过了 12 点又回到 1 点）。而真实的相位差可能超出这个范围：

$$\Delta\phi = \frac{2\pi d}{\lambda} \sin\theta$$

频率越高（$\lambda$ 越短）、麦克风越远（$d$ 越大）、角度越偏（$\sin\theta$ 越大），真实相位差就越大。一旦它超出 $\pm\pi$，测到的值就会被"折叠"回 $[-\pi, \pi]$ 区间——于是**大角度来的声音和另一个角度来的声音，测出的相位差一模一样**，分不清了。

这就是**空间混叠**——本质上是"空间采样不够密"的问题，和时域的 Nyquist 采样定理是同一个道理：采样率不够时，高频信号会"伪装"成低频信号；麦克风间距太大时，大入射角会"伪装"成小入射角。

**例子**：

- 4 kHz 的声音，$\lambda = c/f \approx 8.6$ cm
- 麦克风间距 $d = 5$ cm
- $d/\lambda \approx 0.58 > 0.5$ → **高频时存在角度模糊**
- 对比：同一个阵列对 1 kHz 的声音，$\lambda \approx 34$ cm，$d/\lambda \approx 0.15 < 0.5$ → 没有混叠

**空间 Nyquist 准则**：$d \leq \lambda_{\min}/2$（$\lambda_{\min}$ 是你要处理的最短波长，即最高频率对应的波长）

一个让人清醒的数字：语音最高 8 kHz，对应 $\lambda \approx 4.3$ cm，想完全避免混叠需要 $d \leq 2.1$ cm——很多实际阵列做不到。所以实际系统总是在"阵列尺寸"和"混叠"之间做权衡。

### 数学补充

测得的相位差 = 真实相位差对 $2\pi$ 取余（"折叠"掉超出整圈的部分）：

$$\Delta\phi_{\mathrm{measured}} = \left(\frac{2\pi d}{\lambda} \sin\theta\right) \bmod 2\pi$$

当 $\frac{2\pi d}{\lambda} |\sin\theta| > \pi$（即 $d/\lambda > 1/2$ 且角度足够偏）时，多个不同的 $\theta$ 会产生相同的 $\Delta\phi_{\mathrm{measured}}$。

## Section 5: 房间改变了什么——混响

### 直觉建立

到目前为止，我们假设声波走**直线**从声源到麦克风。但在真实房间里，声波会撞上墙、地板、天花板，然后反弹：

```
声源 ──────────→ 麦克风                直达声 ✅ 有用信息
声源 ──→ 墙 ──→ 麦克风                 一次反射 ❌ 干扰
声源 ──→ 墙 ──→ 地板 ──→ 麦克风        两次反射 ❌ 干扰
……（成百上千条反射路径，每条延迟和衰减都不同）
```

你收到的信号 = 直达声 + 成百上千条反射声。

**想象一个实验**：在房间里拍一下手。麦克风会先录到干脆的"啪"（直达声），然后跟着一串越来越轻、越来越密的小回声（反射）。如果你把这段录音画出来：第一个尖峰是直达声，后面拖着的"尾巴"就是房间对它的回应——这条尾巴叫**房间脉冲响应 (Room Impulse Response, RIR)**。

**关键参数：RT60**

- 房间混响时间的标准度量
- 定义：声音停止后，声压下降 60 dB 所需的时间（60 dB = 声压降到千分之一）
- 典型值：0.2 s（消声室）→ 0.5 s（办公室/普通房间）→ 1.0 s+（大教堂）

**混响对定位的影响**：

| 影响 | 说明 |
|---|---|
| 早期反射 (0–50 ms) | 可能产生**虚假的相关峰**——算法会以为反射方向也有一个声源 |
| 后期混响 | 相位关系被**随机化**——破坏了 TDOA 和子空间方法"只有一个直达声源"的假设 |
| 整体效果 | 低 RT60 → 简单；高 RT60 → 所有方法都退化 |

### 数学补充

房间脉冲响应 (RIR)：

$$h(t) = \sum_{k=1}^{K} \alpha_k \delta(t - \tau_k)$$

- $K$：包括直达声和所有反射的路径总数
- $\alpha_k$：第 $k$ 条路径的衰减系数（反射次数越多、路径越长，$\alpha_k$ 越小）
- $\tau_k$：第 $k$ 条路径的延迟
- 直达声对应最小的 $\tau_k$，通常有最大的 $\alpha_k$

麦克风收到的信号 = 声源信号经过所有路径延迟、加权后的叠加，也就是声源信号和 RIR 的卷积：

$$x(t) = s(t) * h(t) + n(t)$$

其中 $n(t)$ 是麦克风噪声。可以这样理解卷积：声源每一时刻发出的声音，都会在之后的各个时刻（沿各条路径）到达麦克风，把所有这些贡献叠加起来，就是麦克风录到的信号。

## Section 6: 回到问题——声源定位到底难在哪

### 直觉建立

把前五节的知识串起来，理解这个问题的**本质困难**：

| 难点 | 原因 | 谁受影响最大 |
|---|---|---|
| **噪声** | 低 SNR 时相位被噪声扰动 → 相位差测量不准 | TDOA / MUSIC / SRP-PHAT |
| **混响** | 反射产生虚假相位关系 → 看起来像多了几个声源 | 所有传统方法 |
| **多声源** | 多个声源的信号混在一起，相位是非线性混合 → 无法直接分解 | 几乎所有方法 |
| **空间混叠** | 高频时多个角度产生相同相位差 | 需要跨频率联合建模 |
| **真实世界** | 房间形状、温湿度、障碍物 → 无法纯靠公式精确建模 | 传统方法假设失效 |

### 为什么深度学习有优势

| 传统方法 | 深度学习 |
|---|---|
| 需要精确的物理假设（自由场、已知阵列几何） | **从数据中隐式学习**物理规律 |
| 每个模块独立设计（特征 → 估计） | **端到端联合优化** |
| 对未见条件泛化差 | **多条件训练**提升鲁棒性 |
| 多声源场景下表现急剧退化 | 可以通过数据增强 + 架构设计处理 |

- [ ] 为什么不能把麦克风摆得太远（空间混叠）

```python
# 练习1：TDOA 直觉
# 生成两个正弦波，一个比另一个延迟 τ，用互相关估计这个延迟
import numpy as np
f = 1000  # 1 kHz
fs = 16000
t = np.arange(0, 0.01, 1/fs)
s1 = np.sin(2*np.pi*f*t)
tau_samples = 5  # 真实延迟：5 个采样点
s2 = np.sin(2*np.pi*f*(t - tau_samples/fs))
# 计算互相关，找峰值位置（延迟的信号放前面，峰值位置就是正的延迟值）
corr = np.correlate(s2, s1, mode='full')
lag = np.argmax(corr) - len(s1) + 1
print(f"估计延迟: {lag} 采样点, 真实: {tau_samples}")
```

```python
# 练习2：频率与相位差
# 同一个时间延迟，不同频率的相位差不同；高频可能超过 2π
f1, f2 = 500, 4000
tau = 0.0003  # 0.3 ms 延迟（比如 10 cm 间距、声源在正侧面）

```
