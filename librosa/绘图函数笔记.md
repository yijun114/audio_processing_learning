## 1. 总览：哪些程序用了哪些画图函数

| 程序 | 用到的画图函数 | 画了什么 |
|---|---|---|
| visualize.py | `figure` + `waveshow` + `title/xlabel/ylabel` + `tight_layout` + `savefig` | 波形图，存成 wave.png |
| Amplitude_Envelope.py | `figure` + `waveshow` + `plot` + `title` + `show` | 波形 + 包络曲线（红）叠加 |
| RMS.py | 同上 | 波形 + RMS 能量曲线（红）叠加 |
| ZCR.py | `figure` + `plot` + `title` + `show` | 过零率曲线（红） |
| STFT_Spectrogram.py | `figure` + `specshow` + `colorbar` + `title` + `tight_layout` + `savefig` | 频谱热力图 |
| mel_Spectrogram.py | 同上 | 梅尔频谱热力图 |
| SC_BW.py | `subplots` + 子图 `plot` + `set_title` + `suptitle` + `show` | 2×2 四宫格对比图 |

整体套路：**先 `figure` 建画布 → 画内容（waveshow / plot / specshow）→ 加文字（title 等）→ 最后 show 或 savefig**。

## 2. matplotlib 基础画图

### 2.1 `plt.figure(figsize=(宽, 高))` —— 创建画布

```python
plt.figure(figsize=(10, 4))   # 宽 10 英寸、高 4 英寸，宽扁型适合看时间轴长的波形
plt.figure(figsize=(20, 10))  # 更大的画布（Amplitude_Envelope.py 里用的尺寸）
```

- `figsize` 单位是英寸
- 之后所有 `plt.xxx` 的内容都画在这张画布上，不调用它则用默认尺寸

### 2.2 `plt.plot(x, y, color=..., linewidth=...)` —— 画折线

```python
plt.plot(time_scale, waveform_ZCR, color="r")              # ZCR.py
aix[0,0].plot(np.arange(0, len(sc_jazz)), sc_jazz, linewidth=1)  # SC_BW.py
```

- `x` 和 `y` 是**等长**数组，逐点连线
- `color="r"`：颜色。`"r"`=红、`"b"`=蓝、`"g"`=绿、`"k"`=黑，也可写 `"red"`
- `linewidth=1`：线宽（点）

### 2.3 `plt.title / plt.xlabel / plt.ylabel` —— 标题与轴标签

```python
plt.title('Audio waveform diagram')   # 标题（visualize.py）
plt.xlabel('time/s')                  # 横轴标签
plt.ylabel('Amplitude')               # 纵轴标签
```

子图对象上的写法（SC_BW.py）：`aix[0,0].set_title("Jazz")`

### 2.4 `plt.tight_layout()` —— 自动调整边距

```python
plt.tight_layout()   # visualize.py 里的注释："自动调整边距，防止标签被裁掉"
```

放在 `savefig` 之前调用，防止轴标签、标题被裁出画面外。

### 2.5 `plt.savefig('xxx.png')` / `plt.show()` —— 存图与显示

```python
plt.savefig('wave.png')   # 存成图片，格式由后缀决定（png/jpg/svg/pdf）
plt.show()                # 弹窗显示，程序阻塞到窗口被关闭
```

⚠️ 注意顺序：**先 savefig 再 show**。`show()` 弹窗关闭后画布可能被清空，之后 savefig 会存出空白图。

### 2.6 `plt.subplots(2, 2)` —— 一张画布放多个子图

```python
fig, aix = plt.subplots(2, 2)          # 返回 (画布, 2×2 的坐标轴数组)
aix[0,0].plot(np.arange(0, len(sc_jazz)), sc_jazz, linewidth=1)
aix[0,0].set_title("Jazz")             # 每个格子单独起标题
aix[0,1].set_title("Rock")
aix[1,0].set_title("Blues")
aix[1,1].set_title("Orchestra")
fig.suptitle("Spectral Centroid")      # 整张图的总标题
plt.show()
```

- `subplots(行, 列)` 创建子图网格，`aix[i,j]` 是第 i 行第 j 列的坐标轴
- 在子图上画图、加标题都用 `aix[i,j].xxx(...)` 的写法
- SC_BW.py 用它对比四种音乐类型的特征曲线

### 2.7 `plt.colorbar(format=...)` —— 颜色条

```python
plt.colorbar(format='%+2.0f dB')   # STFT_Spectrogram.py
```

- 配合 `specshow` 使用，在热力图旁边加一条颜色条，说明颜色与数值的对应关系
- `format='%+2.0f dB'`：刻度显示成 `+0 dB`、`-30 dB` 这样的格式（`%+` 强制显示正负号，`2.0f` 两位宽度零位小数）

## 3. librosa.display 专用画图

### 3.1 `lb.display.waveshow(data, sr=samplerate)` —— 波形图

```python
data, samplerate = lb.load('testsound.wav', sr=None, mono=False)
plt.figure(figsize=(10, 4))
lb.display.waveshow(data, sr=samplerate)   # visualize.py
```

- 效果：把波形画成填充色块，**横轴自动标成秒**
- `sr` 必须传：不传的话横轴显示采样点序号而不是时间
- 多声道数据（形状 `(声道数, 采样点数)`）会自动画多条曲线

**叠加画法**（Amplitude_Envelope.py / RMS.py）：先画波形，再 `plt.plot` 画特征曲线，两层共用同一坐标轴：

```python
lb.display.waveshow(waveform)
plt.plot(time_scale, waveform_AE_plus, color="r")
```

### 3.2 `lb.display.specshow(S_db, sr=..., x_axis=..., y_axis=...)` —— 频谱热力图

```python
lb.display.specshow(S_db, sr=samplerate, x_axis='time', y_axis='hz')    # STFT_Spectrogram.py
lb.display.specshow(S_db_mel, sr=samplerate, x_axis='time', y_axis='mel')  # mel_Spectrogram.py
```

- 效果：把二维矩阵（频率 × 时间）画成热力图，**数值越大颜色越亮**
- `sr`：换算横轴时间刻度用
- `x_axis`：横轴刻度方式，`'time'` 表示按采样率换算成秒
- `y_axis`：纵轴刻度方式，常用选项：

| y_axis | 含义 |
|---|---|
| `'hz'` | 线性频率刻度（普通频谱图用） |
| `'mel'` | Mel 刻度（梅尔频谱图用） |
| `'log'` | 对数频率刻度 |

⚠️ specshow 只接受二维输入。双声道 STFT 结果是三维的，需先转单声道（见 4.3）。

## 4. 画图前的预处理辅助

这几个不是画图函数，但几乎每次画图前都会用到。

### 4.1 `lb.frames_to_time(frame_scale, hop_length=hop_size)` —— 帧序号转秒

```python
frame_scale = np.arange(0, len(waveform_AE_plus))      # 帧序号 0,1,2,...
time_scale = lb.frames_to_time(frame_scale, hop_length=hop_size)   # Amplitude_Envelope.py
plt.plot(time_scale, waveform_AE_plus, color="r")
```

- 作用：分帧特征（包络/RMS/ZCR）每个值对应一帧，画图前要把"第几帧"换算成"第几秒"
- 换算公式：第 t 帧对应时间 = t × hop / sr

⚠️ **默认参数陷阱**：`frames_to_time` 默认 `sr=22050`、`hop_length=512`。如果音频是 `sr=None` 加载的（原始采样率可能是 44100/48000），**必须显式传 `sr=samplerate`**，否则特征曲线的时间轴会和波形错位。Amplitude_Envelope.py、RMS.py、ZCR.py 里都没传 `sr`，是待修的坑。

### 4.2 `lb.amplitude_to_db(np.abs(D), ref=np.max)` —— 幅度转分贝

```python
D = lb.stft(lb.to_mono(data.T))                    # 复数谱
S_db = lb.amplitude_to_db(np.abs(D), ref=np.max)   # 转分贝后再交给 specshow
```

- 画频谱前**必须先转 dB**：人耳对响度的感受是对数的，声音能量差几万倍听起来只差一点。dB 压缩了这个范围，热力图才能同时看清强音和弱音
- 换算公式：S_db = 20 × log10( 幅度 / ref )
- `ref=np.max`：以最大值为 0 dB 基准，所以整张图的值都 ≤ 0 dB

### 4.3 `lb.to_mono(data.T)` —— 双声道转单声道

```python
D = lb.stft(lb.to_mono(data.T))   # STFT_Spectrogram.py
```

- 把左右声道**平均**成单声道（形状 (2, N) → (N,)）
- 原因是 specshow 只吃二维输入，而双声道 STFT 结果是 (声道数, 频率, 帧数) 三维

## 6. figsize 为什么要用英寸（深入理解）

**为什么是英寸**：matplotlib 为论文出版设计，期刊对插图宽度有硬性规定（IEEE 双栏单栏 3.5 英寸、中文期刊单栏约 8 cm）。所以它按"物理尺寸（figsize）+ 分辨率（dpi）"设计坐标系，保证"印在纸上多大"是可控的。

**怎么理解英寸**：1 英寸 = 2.54 cm。锚点：`(10, 4)` ≈ 25 cm 宽，约 A4 纸宽/笔记本屏宽；`(20, 10)` = 半米宽；`(3.5, 2.5)` ≈ 8.9 cm，论文单栏标准尺寸。像素尺寸 = figsize × dpi（默认 dpi = 100，所以 `(10, 4)` = 1000×400 像素）。

```latex
\text{像素数} = \text{figsize（英寸）} \times \text{dpi}
```

**窗口缩放 vs 存图**：屏幕上拖拽窗口 = 整图等比缩放，只影响预览；`savefig` 的结果只由 figsize × dpi 决定，与窗口大小无关。想存高清图用 `plt.savefig('x.png', dpi=300)`。

**论文插图的正确流程**：figsize 的宽 = 目标栏宽；图内字号 = 正文字号；存矢量格式（PDF/SVG）；插入 Word 后**不缩放**（在 Word 里缩放会破坏图内字号与正文的一致性，PNG 放大还会糊）。

```python
plt.rcParams.update({'font.size': 9})   # 图内字号与正文一致
plt.figure(figsize=(3.5, 2.2))          # 宽 = IEEE 单栏宽，插入后不缩放
# ... 画图 ...
plt.tight_layout()
plt.savefig('fig1.pdf')                 # 矢量格式
```

## 7. 为什么没指定画布，waveshow/specshow 也知道画在哪

**因为 matplotlib 内部维护着两个全局指针**："当前画布"和"当前坐标轴"。所有 `plt.xxx` 都是对"当前"对象操作的：

```python
plt.figure(figsize=(10, 4))   # 新建画布，并把它设为"当前画布"
plt.plot(x, y)                # 实际是"在当前坐标轴上画线"
plt.title('...')              # "给当前坐标轴加标题"
```

**librosa.display 的底层**：`waveshow` / `specshow` 内部先调用 `plt.gca()`（get current axes）——**有当前坐标轴就用，没有就自动新建一个画布 + 坐标轴**（默认尺寸 6.4×4.8 英寸），再画在上面。所以"它知道画在哪"的真相是：不知道，于是现建一个。

`specshow` 还会把热力图登记为"当前图像"，所以后面 `plt.colorbar()` 不用传参数也知道该配谁。

**顺序即状态**：`figure → waveshow → plot → title` 这条链每一步都作用在同一个坐标轴上；`show()` 之后当前状态被清空，下一次 `figure` 重新建立。

**坑**：

- 顺序敏感：如果先 `plot` 后 `waveshow`，`plot` 会先触发自动建画布
- `subplots` 之后，`plt.xxx` 只作用于其中一个子图（通常是最后创建的）——SC_BW.py 用 `aix[i,j].xxx` 显式写法是对的

**两种风格**：

| | 隐式（plt.xxx） | 显式（ax.xxx） |
|---|---|---|
| 优点 | 代码短 | 对象明确、不会画错地方 |
| 缺点 | 状态隐藏、顺序敏感 | 代码稍长 |

`waveshow` / `specshow` 都支持 `ax=` 参数，可以显式指定：

```python
fig, ax = plt.subplots(1, 2, figsize=(12, 4))
lb.display.waveshow(data, sr=sr, ax=ax[0])                               # 画在左图
lb.display.specshow(S_db, sr=sr, x_axis='time', y_axis='hz', ax=ax[1])   # 画在右图
```

建议：单图学习脚本用隐式写法；多子图 / 循环画图用显式写法。

## 8. 常见坑速查

| 坑 | 说明 |
|---|---|
| `frames_to_time` 默认 `sr=22050` | 音频用 `sr=None` 加载时必须显式传 `sr=samplerate`，否则特征曲线和波形时间轴错位 |
| `savefig` 放在 `show` 之后 | 弹窗关闭后画布可能被清空，存出空白图；先 savefig 再 show |
| specshow 吃三维数组 | 双声道 STFT 结果是三维，先 `to_mono` 转单声道 |
| 画热力图不转 dB | 直接用线性幅度画频谱，弱音部分全看不见；先 `amplitude_to_db` |
| SC_BW.py 里 x 轴用了帧序号 | 想换成秒的话，用 `frames_to_time(np.arange(len(y)), sr=..., hop_length=...)` 即可 |
| 隐式 `plt.xxx` 顺序敏感 | `plt.title` 等作用于"当前坐标轴"；多图/循环场景用显式 `ax.xxx` 或传 `ax=` |
| 论文插图在 Word 里随意缩放 | 图内字号与正文脱钩、PNG 放大变糊；按栏宽设 figsize、存矢量格式、插入后不缩放 |
